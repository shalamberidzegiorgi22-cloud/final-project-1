# PIRRO

## პროექტის შესახებ

PIRRO არის ველოსიპედებთან დაკავშირებული მომსახურების პლატფორმის პროექტი. მისი მიზანია გერმანიაში ველოსიპედის მფლობელებს დაეხმაროს საჭირო სპეციალისტის მოძებნაში. პლატფორმა ორი ძირითადი მიმართულებითაა გათვლილი: მეორადი ველოსიპედის ყიდვამდე ტექნიკური შემოწმება და გზაში წარმოქმნილი პრობლემების დროს დახმარება.

პროექტის მთავარი იდეაა, მომხმარებელმა უფრო მარტივად იპოვოს შესაბამისი ხელოსანი, ხოლო სპეციალისტმა თავად გადაწყვიტოს, მიიღებს თუ არა კონკრეტულ შეკვეთას.

## გამოყენებული ტექნოლოგიები

პროექტის შექმნისას გამოყენებულია:

- React
- JavaScript და JSX
- Vite
- HTML და CSS
- React Hooks
- Context API
- LocalStorage
- Lucide Icons
- Git და GitHub

## პროექტის შესაძლებლობები

PIRRO-ს ვებაპლიკაციაში წარმოდგენილია შემდეგი ფუნქციები:

- **მთავარი გვერდი** — პროექტის იდეისა და მომსახურებების გაცნობა.
- **ნავიგაცია** — საიტის სხვადასხვა გვერდზე გადასვლა.
- **მობილური მენიუ** — საიტის გამოყენება მცირე ეკრანებზეც.
- **ენის შეცვლა** — ინტერფეისის სხვადასხვა ენაზე ნახვა.
- **თემის შეცვლა** — მუქ და ღია დიზაინებს შორის გადართვა.
- **რეგისტრაცია და ავტორიზაცია** — მომხმარებლის ანგარიშთან დაკავშირებული ინტერფეისი.
- **კონტაქტის გვერდი** — საკონტაქტო ინფორმაციისა და დაკავშირების საშუალებების წარმოდგენა.
- **About გვერდი** — პროექტის შესახებ ინფორმაციის ნახვა.
- **Contract გვერდი** — შესაბამისი ინფორმაციისა და ფორმების განთავსება.
- **სპეციალისტების ძიება** — სპეციალისტების მოძებნისთვის განკუთვნილი ინტერფეისი.
- **შეკვეთების მართვა** — მომსახურების შეკვეთებთან დაკავშირებული ფუნქციები.
- **AI ასისტენტის ინტერფეისი** — მომხმარებლისთვის დამხმარე ჩატის ვიზუალური ნაწილი.
- **რუკის ვიზუალური ნაწილი** — სპეციალისტების წარმოსაჩენად შექმნილი დეკორატიული რუკის მსგავსი ელემენტი.

## რუკის ვიზუალური ნაწილი

რუკის კომპონენტი შექმნილია საიტის ვიზუალური მხარის გასაუმჯობესებლად. ის არ წარმოადგენს სრულფასოვან, რეალურ რუკის სისტემას და არ გამოიყენება ზუსტი ადგილმდებარეობის დასადგენად ან მარშრუტის გასათვლელად.

ამ ეტაპზე რუკის მსგავს ვიზუალურ ნაწილზე ნაჩვენებია მხოლოდ მაღალი შეფასების მქონე სპეციალისტები. მისი დანიშნულებაა საიტის დიზაინის გამდიდრება და მომხმარებლისთვის სპეციალისტების ვიზუალურად წარმოჩენა.

## ტექნიკური სტრუქტურა

პროექტის კოდი დაყოფილია კომპონენტებად, რათა მისი წაკითხვა და შემდგომი ცვლილებები უფრო მარტივი იყოს.

ძირითადი ნაწილებია:

- `src/main.jsx` — აპლიკაციის გაშვების საწყისი ფაილი.
- `src/components/` — განმეორებით გამოსაყენებელი კომპონენტები.
- `src/pages/` — აპლიკაციის გვერდები.
- `src/` — ძირითადი კოდი და სტილები.
- `public/` — საჯაროდ ხელმისაწვდომი ფაილები.

ეს სტრუქტურა პროექტის სხვადასხვა ნაწილის ერთმანეთისგან გამოყოფასა და კოდის მოწესრიგებაში გვეხმარება.

## ბიზნესმოდელი

PIRRO-ს ბიზნესიდეა ეფუძნება მომხმარებელსა და დამოუკიდებელ ველოსიპედის ხელოსანს შორის კავშირის დამყარებას.

საწყის ბიზნესმოდელში გათვალისწინებულია ორი მომსახურება:

1. ველოსიპედის ტექნიკური შემოწმება ყიდვამდე — €100.
2. გზაში დახმარება — €150.

ბიზნესმოდელის მიხედვით, PIRRO თითოეული შეკვეთიდან 20%-იან საკომისიოს იღებს, ხოლო დარჩენილი თანხა ხელოსანს ეკუთვნის.

ეს თანხები ბიზნესგეგმის ვარაუდებია და არა უკვე დადასტურებული საბაზრო შედეგები. პროექტის საწყის ეტაპზე მნიშვნელოვანია მომხმარებელთა რეალური მოთხოვნის შემოწმება.

## სამომავლო განვითარება

მომავალში პროექტის განვითარება შესაძლებელია მომხმარებლებისა და სპეციალისტების უკუკავშირის საფუძველზე. ერთ-ერთი მნიშვნელოვანი მიმართულება იქნება მომსახურების პროცესის გაუმჯობესება, სპეციალისტების რაოდენობის ზრდა და მომხმარებლისთვის ინფორმაციის უფრო მარტივად მიწოდება.

## დასკვნა

PIRRO-ს მიზანია ველოსიპედის მფლობელებს გაუადვილოს ტექნიკური შემოწმებისა და გზაში დახმარების მიღება. პროექტი აერთიანებს თანამედროვე ვებტექნოლოგიებსა და ბიზნესიდეას, რომლის მთავარი პრინციპია მომხმარებელსა და დამოუკიდებელ სპეციალისტს შორის კავშირის გამარტივება.
